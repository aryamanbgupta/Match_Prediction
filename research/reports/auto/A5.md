# A5 — Feature interactions: ELO × venue, toss × venue

**Status: FAILED** (neither gate metric improved)
**Run:** 2026-07-11, overnight AutoResearch iteration.

## Hypothesis
Matchup strength conditioned on venue character (chase bias, scoring
distribution) carries signal the purely additive features miss. If ELO-diff ×
venue-chase or toss × venue-chase interactions add information, a model trained
with them should beat the fresh baseline on LL and/or ROI.

## What was done
The interaction terms are **products of existing parquet columns**, so no
re-materialization was needed (the ~2h budget line assumed a full tracker
re-walk — unnecessary here). Six mean-centered interaction features were built
(centering constants taken from **train** only, applied to all splits → no
leakage) and written to `data/auto/a5/{train,validation,test}.parquet`:

| feature | definition |
|---|---|
| `ix_elo_top6_x_chase`    | c(top6_batting_elo_diff) × c(venue_chase_win_pct) |
| `ix_elo_top6_x_avgscore` | c(top6_batting_elo_diff) × c(venue_avg_score) |
| `ix_elo_bat_x_chase`     | c(elo_diff_batting) × c(venue_chase_win_pct) |
| `ix_elo_bowl_x_chase`    | c(elo_diff_bowling) × c(venue_chase_win_pct) |
| `ix_toss_x_chase`        | c(toss_winner_is_team1) × c(venue_chase_win_pct) |
| `ix_batfirst_x_chase`    | c(team1_batting_first) × c(venue_chase_win_pct) |

### Correlation check (mandatory pre-training discipline)
All six **pass the redundancy gate** (max |r| vs any existing feature = 0.06–0.12,
far below the 0.5 threshold — mean-centering successfully decorrelates the
interaction from its main effects). But they **fail the target-correlation
floor** the repo established at M6 (|target r| ≥ 0.03):

| interaction | \|r_target\| | max \|r_existing\| |
|---|---|---|
| ix_elo_top6_x_chase    | 0.0181 | 0.087 |
| ix_elo_top6_x_avgscore | 0.0324 | 0.090 |
| ix_elo_bat_x_chase     | 0.0149 | 0.063 |
| ix_elo_bowl_x_chase    | 0.0126 | 0.062 |
| ix_toss_x_chase        | 0.0052 | 0.115 |
| ix_batfirst_x_chase    | 0.0088 | 0.115 |

Every interaction's target correlation is weaker than the weakest *meaningful*
existing feature (top6_batting_elo_diff 0.174, win_rate_diff 0.155,
batting_avg_diff 0.149). Only `ix_elo_top6_x_avgscore` (0.0324) clears the 0.03
floor, and only barely. This is the exact M6 pattern (conditions features:
pass redundancy, fail target floor). Because materialization was free here, the
idea was trained anyway to produce real gate metrics rather than dropped at the
check.

### Training / eval
Recipe A, matched to A1's fresh baseline exactly (same trainer defaults = M7
config, no `--monotone`), differing **only** by the 6 interaction columns
(45 → 51 features). Trained at the **same 5 seeds** A1 used (29,7,13,42,101)
for a paired comparison that isolates the feature effect from seed noise.

**Neither gate metric improved → FAILED.**

## Interpretation
The correlation check predicted this exactly: the interactions carry near-zero
target signal (|r| 0.005–0.032). Two compounding reasons they add nothing:
1. A depth-4 XGBoost already models feature interactions natively — it can split
   on elo_diff then on venue_chase inside one tree. Handing it an explicit
   product is redundant with what the trees already learn, so the extra columns
   only add variance.
2. Venue character is a weak, noisy conditioner at match level; multiplying it
   into ELO dilutes a strong signal (elo_diff, target r 0.174) with a weak one.

This is the fifth match-level feature-engineering direction to die at/after the
correlation check (M3–M6, now A5). The additive-feature frontier is exhausted;
the leverage is in ensembling/architecture (A4's ROI-decorrelation lead) and the
betting layer (A7), not new match-level features.

## What I'd try next
Stop adding match-level features — the target-correlation floor keeps catching
them. Redirect to: (a) the A7 betting-layer rule (slice-conditional edge
threshold — untouched predictions, ROI-only gate); (b) the C-series combination
seeded by A4 (3-way logit-avg {logistic, seed-bag, M7}) that keeps the real
ROI-decorrelation win while averaging out the M7 seed-luck confound. If venue
conditioning is ever revisited, do it as a *learned* venue embedding or a
2-feature target-encoded venue-cluster, not as raw products — but the priors
here are poor.
