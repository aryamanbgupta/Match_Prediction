## Hypothesis

B6 shipped the venue encoder into the default sim path, changing the ball
model's input distribution. Both production ball calibrators were fit on
*venue-blind* val predictions — `vector_scaling_calibrator_v1.pkl` (E5) and
the A15 over-0 calibrator — so their corrections may be stale under venue-ON;
refitting on venue-ON val balls should recover any headroom and re-validate
A15's first-over gain post-re-baseline.

## Verdict

Pre-committed mapping (`b7_gate_analysis.py`, committed 2026-07-12 before any
sim result): GATE1 met + GATE2 held → LANDED; exactly one → TABLED; neither →
FAILED. **GATE 1 NOT MET** (1a met, but 1b's two improvement arms are both
CI-clean regressions), **GATE 2 HELD** → exactly one → **TABLED**.

Substantive reading — the hypothesis is *refuted* for the global vector and
*supported* for the over-0 vector:

- **The E5 v1 global correction is NOT stale under venue-ON.** The 17% refit
  divergence was val-composition noise (or venue-ON val predictions being
  sharper on seen venues) that does not transfer to the 261-match test set;
  applying it actively degrades tail, bowler and batter-fours families. Keep
  stale v1 as the default global calibrator.
- **A15's first-over gain survives the re-baseline.** The refit over-0 vector
  delivers `team_first_over_mae` −0.024 [−0.040, −0.007] under venue-ON —
  matching A15's venue-blind −0.018 / A14's −0.022 — even while sharing a run
  with the harmful refit global (over-0 balls never see the global vector, so
  the components are separable).

Nothing to revert: `1a43a34` is fit+gate harness only (`scripts/auto/`); the
default sim path is byte-unchanged (calibrator loaded via runtime
`--ball-calibrator-path`; artifacts gitignored under `models/auto/b7/`).

## What I'd try next

The decomposition points at a hybrid: **stale v1 global + over-0 vector** as
the shipped default calibrator for the venue-ON path (the current default runs
bare v1 with no first-over correction at all, so A15's validated gain is not
being collected in production). One cheap n=261 seed-43 run of
`OverVectorScalingCalibrator{_global = v1, _v[0] = venue-ON refit over-0}`
paired against the same B6 baseline; gate = first-over gain retained CI-clean
AND no CI-clean regression anywhere the B7 refit-global hurt (tail pool,
bowler_wkts_1plus, guards). Appended as B8. Beyond that, the calibrator lever
looks exhausted — D1–D3 sim correctness fixes and D6 (retrain without balanced
weights, which would obsolete this chain entirely) are the higher-value moves.
