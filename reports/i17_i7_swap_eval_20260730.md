## Reproduce

```bash
uv run python scripts/patch_envelope_cricsheet_ids.py \
  --envelope eval_out/phase5_hier/hier_all_20260425_165622.json \
  --test-dir data/polymarket_test --out eval_out/i17/hier_all_cricsheet.json
for s in 7 13 29 42 101; do for arm in base swap; do
  extra=""; [ $arm = swap ] && extra="--swap-augment"
  uv run python scripts/xgboost_match_v1.py --cmd both \
    --data-dir data/xgb_match_data_i7 \
    --model-dir models/auto/i17/${arm}_seed${s} --monotone $extra --seed ${s}
  uv run python scripts/sim_eval/blend_eval_json.py \
    --sim-json eval_out/i17/hier_all_cricsheet.json \
    --direct-json models/auto/i17/${arm}_seed${s}/test_predictions.json \
    --w 0.0 --out-dir eval_out/i17/${arm}_seed${s}
  uv run python scripts/sim_eval/reslice_eval_json.py \
    --in eval_out/i17/${arm}_seed${s}/hier_all_cricsheet_w0p00.json \
    --odds betting_odds_polymarket.json \
    --out-dir eval_out/i17/${arm}_seed${s}/sliced
done; done
```

Training is exactly reproducible (seeded; determinism gate above), so the
`models/auto/i17/` artifacts are regenerable and stay untracked.
